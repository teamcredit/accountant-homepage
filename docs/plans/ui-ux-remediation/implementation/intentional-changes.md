# 의도한 화면·동작 변경

| 항목 | 변경 이유와 결과 |
|---|---|
| 세무 일정 | 지난 9월 일정은 숨기고 원천세 2026-10-12, 부가세 예정신고 2026-10-26으로 통합. D-day는 서울 날짜 기준. 팝업에 귀속 기간과 공식 출처 표시 |
| 일정 제목 | 실제 표시 범위와 맞지 않던 분기 표현을 ‘주요 세무 일정’으로 변경. 헤더 큐브에는 긴 귀속 기간을 넣지 않아 기존 한 줄 형태 유지 |
| 스크롤 정지 | 중복 Lenis 제거 후 잠재해 있던 강제 2.5초 정지가 갑자기 활성화되지 않도록 제거. 장면의 스크롤 진행과 대화 순서는 유지 |
| 글자 대비 | 메뉴 번호, 선택되지 않은 고객 탭, 블로그 카테고리 숫자, 포털 보조 문구를 읽기 쉽게 조정. 장식용 대형 고객 단계 숫자의 옅은 색은 유지하고 자동 대비 경고 예외 기록 |
| 문의 | 선택한 서비스·견적 요약을 수정 가능한 본문에 미리 표시. 오류·429·응답 지연은 각기 다른 메시지. 실패 시 입력 보존 |
| 데모 | 기간과 KPI를 키보드로 선택 가능. 데모임을 표시하고 이익 계산에서 인건비 차감 기준 일치 |
| JS/동작 줄이기 | 초기 숨김 대신 본문 기본 표시. 모션 초기화된 요소만 스크롤 효과 적용. 동작 줄이기 설정에서는 정적 본문 제공 |
| 오류·빈 화면 | 한국어 404/오류 복구 화면, 검색 실패 재시도, 빈 사례 카테고리에 다른 탐색 경로 제공 |

공식 일정 근거: [국세청 2026년 10월](https://www.nts.go.kr/nts/ad/taxSchdul/selectList.do?mi=135747&taxMonth=10&taxYear=2026). [2027년 1월](https://www.nts.go.kr/nts/ad/taxSchdul/selectList.do?mi=135747&taxMonth=1&taxYear=2027)은 확인 당시 미게시라 기존 1월 항목을 보류했다.

영상은 실제 재생하고 휠 스크롤로 캡처했기 때문에 같은 번호의 전후 이미지라도 영상 프레임과 정확한 스크롤 진행률이 조금 다르다. 픽셀 완전 일치를 주장하지 않는다. 홈 대화 장면과 포털 카드 합류 장면을 포함해 대표 화면을 직접 비교했다.
